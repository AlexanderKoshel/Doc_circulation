# Материалы для РГР2

Ветка `rgr2` создана от `master` для расчетно-графической работы №2 по Microsoft SQL Server (T-SQL).

## Учебные PDF, приложенные к заданию

1. `Практический материал 1  к РГР2 Основные понятия.pdf`
2. `Практический материал 2 к РГР2 Создание, удаление и изменение БД.pdf`
3. `Практический материал 3 к РГР 2 Создание таблиц и обеспечение целостности данных.pdf`
4. `Практический материал 4 к РГР2  изменение таблиц.pdf`
5. `Практический материал 5 к РГР2. Обеспечение целостности данных.pdf`
6. `Практический материал 6 к РГР2. Добавление к таблице новой записи.pdf`
7. `Расчетно-графическая работа 2 (индивидуальное задание).pdf`

> **Статус:** этот файл — перечень. Оригинальные бинарные PDF пока не загружены в GitHub: подключённый инструмент поддерживает запись текстовых файлов, но не перенос файлов из вложений чата в двоичные Git-объекты. Не считайте данное оглавление заменой PDF.

## Краткое содержание индивидуального задания

Создать T-SQL базу данных с описанными файлами данных и журнала; разработать таблицы в 3НФ с именованными ограничениями и внешними ключами; создать диаграммы в SSMS; внести не менее 10 записей в каждую таблицу; предоставить скриншоты, комментированные скрипты и резервную копию базы.

## Загрузка оригинальных файлов

Поместите семь PDF из вложений в каталог `materials/` локальной копии репозитория в ветке `rgr2`, затем выполните `git add materials && git commit -m "Add original RGR2 reference PDFs" && git push -u origin rgr2`.
